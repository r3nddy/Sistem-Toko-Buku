# 03 — Paket `app/db/`

`app/db/` berisi lapisan database SQLAlchemy: kelas dasar deklaratif dan
dependency sesi. Ini paket kecil (3 berkas ≤ 11 baris kode) tetapi menjadi pintu
masuk **jalur ORM** yang dipakai banyak fitur.

---

## 1. Struktur

| Berkas | Tujuan | Simbol | Dipakai oleh |
|--------|--------|--------|--------------|
| `base.py` | `Base` deklaratif | `Base(DeclarativeBase)` | Semua modul `app/models/` |
| `session.py` | Engine + sesi + dependency | `engine`, `AsyncSessionLocal`, `get_db()` | Router (`books`, `community`, `reviews`, `marketplaces`, `ai`, `book_advisor`) dan repository ORM |
| `__init__.py` | Docstring paket | — | — |

---

## 2. `base.py`

```python
# app/db/base.py
class Base(DeclarativeBase):
    """Kelas dasar bersama untuk seluruh model ORM aplikasi."""
```

**[Fakta]** Semua model di `app/models/` mewarisi `Base`, sehingga
`Base.metadata` memuat seluruh tabel dan dapat dipakai Alembic
(`migrations/env.py` menetapkan `target_metadata = Base.metadata`).

**[Evaluasi]** Ini contoh **inheritance** paling dasar dan paling penting di
proyek: satu kelas induk memberi perilaku deklaratif (pemetaan ke tabel) ke
belasan model.

---

## 3. `session.py`

### Fakta
```python
# app/db/session.py
engine = create_async_engine(
    settings.database_url,
    echo=False,
    pool_pre_ping=True,
    pool_recycle=settings.DATABASE_POOL_RECYCLE_SECONDS,
    **({"poolclass": NullPool} if os.getenv("VERCEL") else {}),
)
AsyncSessionLocal = async_sessionmaker(engine, class_=AsyncSession, expire_on_commit=False)

async def get_db() -> AsyncGenerator[AsyncSession, None]:
    """Berikan satu sesi database untuk satu permintaan, lalu tutup."""
    async with AsyncSessionLocal() as session:
        yield session
```

Keputusan yang tertulis di docstring modul:

| Keputusan | Alasan (dari docstring) |
|-----------|-------------------------|
| `pool_pre_ping=True` | Mengganti koneksi yang sudah diputus server sebelum dipakai |
| `pool_recycle=settings.DATABASE_POOL_RECYCLE_SECONDS` | Supabase memutus koneksi menganggur; mencegah "freeze" di UI |
| `NullPool` di Vercel | Proses function dibekukan antar permintaan; koneksi pool tidak pernah dipakai lagi dan menghabiskan kuota Supavisor |
| `expire_on_commit=False` | Objek tetap bisa dibaca setelah `commit()` (dipakai saat menyusun respons) |
| `get_db` generator dependency | Satu sesi per permintaan, otomatis ditutup termasuk saat error |

### Penggunaan (fakta)
`get_db` dipakai dalam dua bentuk di router:

1. **Langsung** sebagai parameter: `db: Db` di mana
   `Db = Annotated[AsyncSession, Depends(get_db)]` (mis. `app/api/v1/community.py`, `app/api/v1/ai.py`).
2. **Di dalam provider** service: `comparison_service(db)` di
   `app/api/v1/marketplaces.py`, yang menyusun repository ORM dari sesi yang sama.

**[Evaluasi]** Bentuk kedua penting: service dan endpoint berbagi **satu**
sesi, sehingga `commit()` hanya terjadi sekali dan perubahan yang ditulis
service terlihat oleh endpoint. Komentar ini sendiri ada di
`app/api/v1/community.py`.

## 4. Bagian "pembagian dua jalur data" di docstring (fakta, sudah diperbarui 2026-10-30)

**[Fakta]** Docstring `app/db/session.py` dan `app/db/__init__.py` kini
menjelaskan pembagian terkini: `get_db` dipakai router `books`, `community`,
`reviews`, `marketplaces`, `ai`, dan `book_advisor` serta repository ORM yang
mereka susun (`OrmBookRepository`, `OrmGroupRepository`/`OrmMemberRepository`/
`OrmMessageRepository`, `OrmReviewRepository`, `OrmMarketplaceSourceRepository`/
`OrmMarketplacePriceRepository`, `SqlAdvisorCatalog`); service CRUD sederhana dan
laporan (`category_service`, `promo_service`, `cart_service`, `order_service`,
`inventory_service`, `dashboard_service`, `payment_service`) tetap memakai
PostgREST.

**[Fakta]** Sebelumnya kedua docstring menyatakan "jalur ini hanya dipakai
endpoint `books`" — pernyataan itu usang dan telah diganti.

**[Rekomendasi]** Bila menambah pemakai `get_db` baru, perbarui daftar ini agar
tetap akurat.

---

## 5. Kesimpulan paket

- **[Fakta]** `app/db` hanya berisi `Base` dan `get_db`; tidak ada logika bisnis.
- **[Evaluasi]** Ukurannya kecil namun sehat: engine dan opsi pool dijelaskan
  dengan alasan di satu tempat.
- **[Rekomendasi]** Jaga agar `get_db` tetap satu-satunya cara membuat sesi;
  hindari `AsyncSessionLocal()` langsung di service agar siklus hidup sesi tetap
  dipegang FastAPI.
